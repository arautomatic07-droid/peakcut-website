PEAKCUT WEBSITE — GITHUB PAGES

1. Replace CONTACT_EMAIL in index.html with an email address you monitor.
2. Complete every [BRACKETED PLACEHOLDER] in terms.html and privacy.html.
3. Review the privacy policy against PeakCut's actual code/data flows, especially:
   - whether videos remain local or are uploaded to a server
   - what TikTok profile fields are received
   - where OAuth access/refresh tokens are stored and encrypted
   - who can access tokens and how revocation/deletion works
   - hosting, logs, analytics and retention periods
4. Do not publish until the legal/business identity and contact details are complete.
5. In GitHub, create a PUBLIC repository named peakcut.
6. Upload index.html, terms.html, privacy.html (README is optional) to the repository root.
7. Repository Settings > Pages > Build and deployment:
   Deploy from a branch; Branch main; Folder /(root); Save.
8. Wait for GitHub Pages to deploy. Your pages should be:
   https:// arautomatic07-droid.github.io/peakcut/
   https:// arautomatic07-droid.github.io/peakcut/terms.html
   https:// arautomatic07-droid.github.io/peakcut/privacy.html
   (Remove the space after https://; shown spaced here only for readability.)
9. Open each URL in a private/incognito browser window to confirm public access.
10. TikTok may require URL ownership verification. Follow the exact verification method shown in the TikTok Developer Portal. Do not assume GitHub Pages supports every verification method or that verification is automatic.
